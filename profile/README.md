# kochou framework
### C++ 23 | API Vulkan | Xmake

Framework layers:
* [kochou-registry](https://github.com/kochou-framework/kochou-registry) - framework components collection
* [kochou](https://github.com/kochou-framework/kochou) - framework core
* [ktl](https://github.com/kochou-framework/ktl) - framework template library
